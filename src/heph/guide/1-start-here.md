# Start here

## What is Heph?

Heph answers questions from your own files and shows where each answer came from.
You ask in plain words. Heph finds the passages that match, sends them to your model,
and prints the answer with citations such as [E1] that point back to the file and page.

This armory is the Heph guide. It holds these pages about Heph itself, so you can learn
Heph by asking Heph. Try: "how do I add my own files?" or "which models can I use?"

## What is an armory?

An armory is a folder of files that Heph answers from. Every file in the folder is
material: notes, PDFs, Word documents, slides, spreadsheets, code. Heph never changes
your files. It keeps its index and chats in a hidden `.harness` folder inside the armory.

You are in one armory at a time. Its name is shown under the prompt, next to the model.

## The first three things to do

1. Ask a question here, to see how answers and citations look.
2. Make your own armory: run `heph init` in a folder of your files, or type `/armory`.
3. Pick your model with `/model` if the default local server is not the one you use.
